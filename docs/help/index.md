# PactPal help

PactPal is for freelancers and small sellers who are paid through PayPal. It turns the deal you agree in a chat into a signed agreement, sends a PayPal invoice for each agreed stage, records every step in an evidence log nobody can quietly edit, and gets you ready if a buyer disputes a payment.

> PactPal currently runs in test mode. No real money moves.
