# Build plan

The end-to-end build in ten phases (0–9), in dependency order. Phases 1–5 form the core loop; 6–8 layer on top; 9 ships it. Phase 7 (deal space) was added by the owner on 8 November 2026; the partner tools and shipping phases moved to 8 and 9. See [product.md](product.md) for what each feature does.
